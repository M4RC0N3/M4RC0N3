# Hi, I'm Marcone Ribeiro 👋

Tech Lead based in Bahia, Brazil 🌞. I build products that combine software engineering and AI to solve real business problems: AI agents on WhatsApp, automation and the web and mobile apps around them.

- 🧭 Tech Lead at **Rumo Tech**, leading the team behind **Seu AgenteIA** (AI agents on WhatsApp for businesses) and **GarçomIA** (AI-powered restaurant service)
- 🤖 Working daily with LLMs (OpenAI, Anthropic), agent architectures and the WhatsApp ecosystem (Meta Official API)
- 🛠️ Full stack: Python and Node.js on the backend, React, Ionic and Svelte on the front end
- 🎓 Software Engineering student at FIAP
- 🎮 Still love games

## What I'm building 🚀

| Project | What it is | Stack highlights |
|---|---|---|
| **Seu AgenteIA** | AI agents on WhatsApp for sales, support and billing | Python, Node.js, LLMs, Meta WhatsApp API, MySQL, AWS |
| **GarçomIA** | AI assistant for restaurant ordering and service | Python, LLMs, vector search, Docker |
| **Engatei** | Marketplace connecting driving students and instructors ([app.engatei.com.br](https://app.engatei.com.br)) | Ionic React PWA, Svelte landing, WhatsApp login, PostHog |
